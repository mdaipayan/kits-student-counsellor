# KITS Student Counselling & Mentoring System

Initial Streamlit prototype for one counsellor with a maximum of 35 students:

- 1st Year: up to 20
- 2nd Year: up to 5
- 3rd Year: up to 5
- 4th Year: up to 5

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

The first version includes:
- Dashboard
- Student records
- Counselling session records
- Basic academic/attendance database tables
- Reports and CSV export
